# ADR（me）

このリポジトリのサイト向け決定ログ。スライド用 ADR（Linear / Slides プロジェクト、アーカイブ済み）や My Ingestion の ADR とは番号が別系統。

新しい決定は番号を足す。改訂したら状態を変え、後継を張る。

## 書き方

- 状態: 採択 / 提案 / 改訂済み / 廃止
- セクション: 文脈 → 決定 → 結果 → 検討した代替
- 実装の都合で契約を上書きしない
