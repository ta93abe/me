# ta93abe.com

[Takumi Abe](https://ta93abe.com)（ta93abe）の個人サイトです。データ基盤と CI を書くソフトウェアエンジニアで、絵と音楽も置いています。

このリポジトリは、そのサイトのソースコードです。

## 技術

Astro、Tailwind CSS、TypeScript で書き、Cloudflare Workers で配信しています。

## ローカルで動かす

Node.js 22.12 以上と pnpm が必要です。

```sh
pnpm install
pnpm dev
```

http://localhost:4321 で開けます。環境変数は不要です。ブログの本文はこのリポジトリにないので、ローカルの Blog は空です。
